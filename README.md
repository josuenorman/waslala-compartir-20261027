# Waslala — enlace temporal

Entrega ligera de un proyecto QGIS con fotografías y coordenadas GPS, publicada con autorización de su titular.

El archivo `Waslala_Ligero.rar` se distribuye en la sección **Releases**, no en el historial del código.

## Abrir el proyecto

1. Descargue y descomprima el RAR completo.
2. Abra `Waslala_Ligero/Capas_y_proyecto/Diagnostico_Waslala.qgz` en QGIS 3.40 o posterior.
3. Conserve las subcarpetas `Fotos`, `Capas_y_proyecto` y `Scripts` juntas.

Los mapas base requieren Internet. Las fotografías son copias optimizadas de hasta 2560 píxeles, JPEG 88.

## Disponibilidad temporal

Una tarea de GitHub Actions revisa cada hora si el RAR ha cumplido **10 días desde su subida** y, en ese caso, elimina únicamente ese archivo adjunto de la Release.

**No es una caducidad exacta:** la ejecución puede retrasarse o fallar si GitHub Actions no está disponible o se deshabilita. La eliminación no revoca copias ya descargadas ni garantiza la desaparición inmediata de todas las cachés.

El repositorio y su documentación permanecerán publicados. Los respaldos locales no se eliminan.
